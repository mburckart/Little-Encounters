Little Encounters

A cute installable iPhone-style web app for counting run-ins.

Features:
- One-tap encounter button
- Tiny celebration animation on every tap
- Today's count
- Current-month total
- Lifetime total
- Cute month-by-month history cards
- Recent sightings with date and time
- Undo last tap
- Automatically starts a fresh visible count each month
- Old monthly totals stay saved
- Imports data from the earlier Friend Run-In Counter version when opened on the same site/browser
- Works offline after first successful load

To install on iPhone:
1. Upload these files to any HTTPS static host.
2. Open the hosted page in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Little Encounters from its icon.

Important:
The data is stored in Safari/app website storage on that device. Clearing website data can erase it.
